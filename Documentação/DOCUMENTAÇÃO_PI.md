**1\. CONTEXTUALIZAÇÃO DA EMPRESA** 

1.1 HISTÓRICO: 

A Keenko é uma startup brasileira de tecnologia para a saúde (HealthTech), fundada em 27 de fevereiro de 2025\. Com 16 meses de trajetória em pesquisa e desenvolvimento, a companhia consolidou-se a partir da identificação de uma lacuna crítica no mercado (dor real) de bem-estar: a ausência de autonomia do indivíduo sobre seus dados e rotina nutricional. 

A empresa opera na intersecção entre ciência da nutrição e inovação digital, buscando transformar hábitos complexos em fluxos de dados gerenciáveis e intuitivos. 

A Keenko se projeta rumo a tornar-se a principal referência nacional no setor de alimentação saudável mediada pela tecnologia. Sua estratégia de crescimento está dividida em duas fases fundamentais, a consolidação digital – Estabelecendo uma base de usuários sólida através de aplicações mobile de alta performance – e a expansão do ecossistema – Evolução de uma ferramenta de software para um hub completo de saúde, integrando serviços de alimentação personalizada e análise de dados preditiva.

1.3 DIAGNÓSTICO TECNOLÓGICO: 

Atualmente, a Keenko utiliza de softwares para desenvolvimento de projetos e comunicação entre equipe de desenvolvimento, sendo eles: 

● Visual Studio Code: Software para o desenvolvimento das partes de back-end e front-end; 

● Figma: Software para o desenvolvimento do design (parte visual) do aplicativo; 

● Mysql Workbench: Software para o desenvolvimento do banco de dados do aplicativo; 

● Pacote Office e Pacote Google: Conjunto de softwares que permite a documentação e detalhamento de dados da empresa em planilhas; ● WhatsApp: Software para a comunicação formal entre a equipe de desenvolvimento e o Product Owner, mostrando o que desenvolveram até então; 

● Discord: Software que permite a comunicação entre a equipe, organização entre canais de texto e de chamada de voz — para daily scrums. 

1.4 RESTRIÇÕES E IMPACTOS: 

O Sistema possui limitações quanto ao uso da IA, sendo necessário uma grande quantidade de dados para poder usar Machine Learning, sendo algo que será atualizado futuramente. 

Os principais setores que serão atingidos dentro da empresa devido a esse projeto serão os setores de Tecnologia da Informação devido ao uso de alta tecnologia, e ao setor financeiro devido ao custo do projeto e a geração de lucro.
