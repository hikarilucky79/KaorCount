# Índice de funções do KaorCount

A numeração dos comentários foi separada por camada para facilitar a consulta no TCC. Os identificadores são globais; funções adicionadas depois recebem novos IDs ao final, sem renumerar as anteriores.

- [Índice do frontend](INDICE_FUNCOES_FRONTEND_TCC.md): aplicativo React Native e páginas públicas.
- [Índice do backend](INDICE_FUNCOES_BACKEND_TCC.md): API e serviços Python.

O frontend contém 268 funções documentadas; o backend contém 303. No total, são 571 funções nomeadas. Os IDs do frontend são `F001–F004` e `F307–F570`; os do backend são `F005–F306` e `F571`.

Não foram encontradas declarações formais de `enum` no escopo documentado. Callbacks anônimos, testes, scripts de manutenção e código de terceiros permanecem fora do escopo.
